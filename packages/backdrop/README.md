# Backdrop

Node backend + Chromium kiosk SPA that plays looping visualizer videos on the display.
Spec: [../../docs/specs/backdrop-spec.md](../../docs/specs/backdrop-spec.md).

**First milestone:** Chromium boots to a hello page in kiosk mode; then Node+WebSocket;
then hardcoded video loop; then crossfades; then `/api/scan`; idle; library sync.
